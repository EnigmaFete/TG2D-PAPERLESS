Guide d'Installation

Choisissez votre Méthode de Déploiement

Déployez selon vos préférences : conteneurs Docker pour l'isolation complète ou installation Windows directe sans Docker.

1

Cloner le dépôt et entrer dans le dossier

Récupérez le projet et ses configurations complètes de conteneurs :

git clone https://github.com/EnigmaFete/TG2D-PAPERLESS.git cd TG2D-PAPERLESS
2

Démarrer la stack de 5 micro-services

Paperless, PostgreSQL, Valkey, Gotenberg et Tika sont automatiquement instanciés :

docker compose up -d
3

Accéder à l'interface TG2D

Ouvrez votre navigateur web sur le port configuré :

http://localhost:8001
1

Préparer le PC Serveur Windows au Bureau

Sur n'importe quel PC Windows 10/11 ou Windows Server connecté au réseau de l'entreprise, copiez le dossier windows-host/.

2

Lancer l'installation automatique en 1 clic

Clic droit sur install.bat > Exécuter en tant qu'administrateur. Le script configure SQLite, installe Tesseract et applique le thème TG2D.

3

Démarrage et accès partagé équipe

Double-cliquez sur start-server.bat. L'adresse IP locale s'affiche instantanément :

http://192.168.1.X:8000
